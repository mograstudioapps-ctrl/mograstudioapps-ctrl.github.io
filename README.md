# Mogra Studio website

Public website for Mogra Studio games, served by GitHub Pages at
https://mograstudioapps-ctrl.github.io

- `privacy.html`: privacy policy (Gulal Sort, Jaali Blocks). Keep it in step with what the games do.
- `terms.html`: terms of service (needed as a Google Play trader account).
- `app-ads.txt`: added after the games are published, with the exact line AdMob shows.

Source of truth for game behaviour: the `mogra-studio` repository.
